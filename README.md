# React Quiz App

A customized React quiz app based on the Academind starter project. Tests your React knowledge with 7 questions and shows your score at the end.

## Prerequisites

- [Node.js](https://nodejs.org/) v18 or higher
- npm (comes with Node.js)

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/bernmoreno/quiz-app-pages-2026.git
   cd quiz-app-pages-2026
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

## Running Locally

Start the development server:
```bash
npm run dev
```

The app will be available at `http://localhost:5173`.

## Building for Production

```bash
npm run build
```

The built files will be output to the `dist/` folder.

To preview the production build locally:
```bash
npm run preview
```

## Deployment

This project is deployed to GitHub Pages via GitHub Actions.

Live site: [https://bernmoreno.github.io/quiz-app-pages-2026/](https://bernmoreno.github.io/quiz-app-pages-2026/)

Every push to `main` automatically builds and deploys the app.

To set up Pages on a fork:
- Go to **Settings → Pages → Source: GitHub Actions**
